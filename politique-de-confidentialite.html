2. Objet et cadre juridique

Cette politique a pour but de vous informer sur la manière dont sont gérées les données susceptibles d'être traitées lors de votre navigation sur ce portfolio, conformément au Règlement Général sur la Protection des Données (RGPD - Règlement UE 2016/679) et à la loi Informatique et Libertés.

3. Hébergement et journaux de connexion (Logs)

Ce site est hébergé de manière statique via le service GitHub Pages, fourni par la société GitHub, Inc.

Coordonnées de l'hébergeur :
GitHub, Inc.
88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis
Site web : https://pages.github.com

Dans le cadre du fonctionnement technique de l'hébergement, GitHub Inc. peut collecter automatiquement des données techniques dans ses journaux serveur (server logs), telles que :

  • Votre adresse IP ;
  • Le type et la version de votre navigateur web ;
  • Le système d'exploitation utilisé ;
  • La date, l'heure et la page consultée.

Base légale : Ces données sont traitées sur la base de l'intérêt légitime (article 6.1.f du RGPD) de l'hébergeur pour garantir la sécurité, la stabilité et la prévention des attaques informatiques sur ses serveurs.

4. Données personnelles & Formulaires

Ce site ne comporte aucun formulaire de contact, aucun espace membre et ne collecte directement aucune donnée personnelle à votre insu. Aucun outil de mesure d'audience commercial (type Google Analytics) ni script de suivi publicitaire n'est intégré.

5. Cookies et technologies de suivi

Aucun cookie de suivi, analytique, publicitaire ou nécessitant le consentement préalable de l'utilisateur n'est déposé sur votre terminal lors de la consultation de ce site. Le site fonctionne intégralement sans aucun dépôt de cookie tiers.

6. Transfert de données hors de l'UE

En raison de l'hébergement du site sur les serveurs de GitHub Inc. situés aux États-Unis, certaines données techniques de connexion (adresses IP) peuvent faire l'objet d'un transfert vers les États-Unis. GitHub s'engage à respecter les cadres de protection des données applicables (Cadre de protection des données UE-États-Unis / Data Privacy Framework) pour garantir la sécurité et la confidentialité de ces informations.

7. Liens vers des sites tiers

Ce portfolio contient des liens vers des plateformes externes (notamment LinkedIn et GitHub). En cliquant sur ces liens, vous quittez ce site. L'éditeur n'exerce aucun contrôle sur les politiques de confidentialité ni sur les pratiques de ces sites tiers.

8. Vos droits (RGPD)

Conformément à la réglementation sur la protection des données personnelles, vous disposez des droits suivants concernant vos données :

  • Droit d'accès et de rectification ;
  • Droit à l'effacement (« droit à l'oubli ») ;
  • Droit à la limitation du traitement.

Pour toute demande concernant la gestion du site, vous pouvez me contacter directement via LinkedIn ou GitHub. Si vous estimez, après m'avoir contacté, que vos droits ne sont pas respectés, vous avez le droit d'introduire une réclamation auprès de la CNIL (Commission Nationale de l'Informatique et des Libertés — www.cnil.fr).
